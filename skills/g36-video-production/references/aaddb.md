# AaddB 混剪 SOP

## 前置资产

- A 原片及可用的原生横竖版；如果只从旧成片取 A，标清母片、是否保留原包装。
- B 原片或素材库、素材编号；已有对应表就提交 A→B 映射，否则给 A 的卖点和预期承接方向。
- 已验收的转场样例或参考视频；可明确覆盖默认转场参数。
- 目标尺寸、语言、CTA、单层卡套和对应原生尺寸尾板；要预约、体验、下载中的哪些版本由本批指令决定。
- 文案、术语、BGM、免责声明等按需提供；给正式编号/命名表和交付路径。

## 1. 盘点配对与出片矩阵

读实际尺寸、帧率、音轨，抽看开头和结尾；实际 1920×1080 可能是竖片套横框。记录原生方向、已有卡套、已有尾板。已有配对表就按表执行；没有才看 A 尾与 B 首的卖点、动作、情绪、画幅兼容性，给候选确认，不凭文件名当已匹配。首次入库可复用现有 aaddb 联系表工作流，已有缓存优先读缓存。

按行建立：A编号、B编号、语言、输出尺寸、卡套、尾板 CTA、目标名称及目录。未指定不额外做其他 CTA，不拿错素材补齐。

## 2. 定切点

- A 尾：先定位最后一个有效口播字和最后有效动作。样片中若需在口播结束前起转，最早从最后一个有效字开始，原声仍须播完整。如果台词后还有关键动作，优先保住动作再转场。A 的尾段要继续运动，不能截最后一帧冒充推进。
- B 尾：试听最后一句，逐帧找旧尾板首帧。尾板的画面、声音一起在渲染时裁掉；把正文最后一个字和有效动作保留。没有旧尾板则记录“无”，不盲裁固定秒数。
- 横竖分别核对切点。记录素材编号、画幅、A 有效口播/动作、B 正文结束、旧尾板首帧；若对白和旧尾板已混叠到无法干净切除，如实列为异常。

## 3. 样片与批量

做一条完整 A→B→新尾板样片。默认沿用已验收的轻微推近加四周轻模糊、中心清晰，约 0.4 秒起调；不夸张放大、不定格、不吞字。B→末尾只用 B 的正常画面参与，必要时做短音频淡入淡出。新效果经确认后才批量。需要新做 A 字幕时，以词级时间戳结合最终文案；BGM 和免责声明只按本批需求添加，不改已有确认版。

画幅优先同向配对。原生 9:16 全屏，不套竖框；横、竖确需延展才用确认卡套。已经带一层包框的素材作为例外登记，不套第二层，也不能当成原生横版。横、竖必须各用对应尺寸和语言 CTA 的尾板。常规输出 MP4、H.264、AAC、30fps。命名优先用正式表；样片可用 A短名+B编号+B短名+尺寸。

## 4. 质检与交付

逐条验证实际分辨率、帧率、音轨、完整解码、文件名和矩阵数量；各接点抽连续帧并试听，确认最后一句完整、没有旧尾板残帧、黑白闪帧、冻结、马赛克或双重包框。核对尾板实际字样和可见 CTA。报告缺素材/失败项，原片保留，只有验收通过的输出进入正式目录。
