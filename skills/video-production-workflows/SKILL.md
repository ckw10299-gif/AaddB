# 视频生产工作流

## 选择流程

- **AaddB**：A 面接一个或多个 B 面、去旧尾板、做推进转场，读 [AaddB 混剪 SOP](references/aaddb.md)。可复用本机现有 aaddb 的缓存和脚本，但不为此技能改动原 aaddb。
- **多语言本地化与画幅适配**：读 [本地化 SOP](references/localization.md)。目标语言、画幅、配音、字幕、卡套和尾板按当前项目，不沿用其他人的参数。
- **查看实际执行**：读 [执行记录及源码索引](references/execution-record.md)。源码根据本次实际运行记录归档，个人和项目输入值已剔除。存档不是独立的一键剪辑器，不能拿旧脚本直接覆盖新项目。

## 通用执行与验收

先查真实素材和输出矩阵，再按已验收规则制作。新转场或新字幕遮盖样式先出代表样片，确认后批量；沿用已确认配置、用户明确要求直接批量时不用重复询问。只扫描、复制、改名、重做和原名替换是不同授权；保留源片和共享盘内容。没有授权时不发布、上传或覆盖。

抽帧判断真实画幅和是否已有卡套。原生比例优先保留；任何裁切、卡套、虚化和包装按当前项目配置。尾板按语言、实际输出尺寸、CTA 匹配。没有正式物料的版本不冒充已完成。原名替换前将旧版作可恢复备份；替换后回读用户指定目录，遇占用逐条报告。

以 **素材编号 × 语言 × 实际尺寸 × CTA（需要时）** 对账。逐条核对文件名、编码、帧率、音轨、完整解码和尾板；查看关键帧并试听切点，不能以导出成功代替内容验收。异常记录：编号、语言、尺寸、问题、位置。只把通过的成片放正式目录。

## VoxCPM 部署入口

- **官方安装地址**：https://github.com/OpenBMB/VoxCPM 。官方安装说明：https://voxcpm.readthedocs.io/en/latest/installation.html 。
- 只有确需生成配音且没有可用环境时，才部署；已确认的 WAV 足够时不安装。先读 [VoxCPM 自动安装、启动与排查](references/voxcpm.md)。
- Windows 自动安装器：[scripts/install-voxcpm.ps1](scripts/install-voxcpm.ps1)。先跑 `-PlanOnly`；实际部署选定目标后，创建独立环境、安装依赖、下载或复用权重，生成并验证一条 WAV。实装和验证是不同阶段；只看到 WebUI 或 HTTP 200 不算安装验收。
