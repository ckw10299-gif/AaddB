# 海外完整本地化与简中适配 SOP

## 前置资产与矩阵

- 纯净母片（无中文字幕/口播，尽量保留音乐、音效）及中文版参考；或者只有带烧录中文字幕和中文原混音的成片。
- 确认外语稿；没有时用中文参考、术语表和发音要求本地化。品牌 `lumi` 等写法按项目统一。
- 确认的 EN、JP、TC、KR WAV；若没有，提供可使用的声音参考 WAV、对应原台词、各语言口音/风格。仅有中文混音时需独立 BGM；要保留独立音效须额外提供。
- 对应语言和尺寸的 PNG 卡套、尾板（语言/实际尺寸/CTA）、素材编号题材表、日期命名和目标目录。
- 默认每条 × 四语言 × 四尺寸 = 16 条，字幕和配音各四份；不同原片分别做矩阵。缺资产记行，不拿其他语言代替。

## 1. 选择母片与声音路线

有纯净版则只用纯净母片画面，保留音乐与音效；新版台词使用目标语言。只有中文混音版则静音主体原轨，使用独立 BGM＋目标语配音，并记录每段旧字幕出现区间及画幅上的边界。确认原片是否已有尾板，若有则从精确首帧裁除画面与声音；主体播放速度不改。

有确认 WAV 优先复用；需要生成时按 [VoxCPM 安装与生成](voxcpm.md) 操作。每条原片、每语言仅制作一套对齐 WAV 和字幕时间线，供不同尺寸复用。相同脚本在不同片长原片上的对齐参数需各自计算。

## 2. 配音时长、字幕和混音

1. 以主体结束点减约 0.5 秒为最后有效发音目标。检查的是有效口播，不是 WAV 容器时长。不要求逐镜对齐，不变速主体画面。先处理过长停顿、适度变速保持自然；差太多就精简或调整译文并重新生成，禁止截最后一句。
2. 对齐确认稿与最终发音时间。可用词级时间戳辅助，再复核产品词、数字、日/中/韩识别误差。烧录字幕并单独交付 SRT。默认单行，同画幅字号和位置固定；长句合理拆成连续两条，避免为了塞下去一条条缩字。对照画幅实际窗口检查字形和视觉大小，不只比较字号。
3. 有中文烧录字时，沿用确认样式：**白字、黑描边、不透明白色圆角底**。每句白底宽度取「目标句所需」与「该时间段中文所需遮盖」较大值，再留边距。换句、停顿、收尾如果旧中文字幕仍在，保持挡板或保留上一句到合适时点，确保不露边、不闪现。不同原片各自测位置，不固定一组坐标。
4. 混音人声优先，BGM 可听但不压字；先减音乐或单独抬人声，不把总音量整体硬拉。检查开头、口播密处、最后一句与尾板开始；主体在尾板前约半秒继续正常播放，可保留音乐/音效，不补黑屏。

## 3. 画幅、尾板与成片

| 输出 | 处理 |
| --- | --- |
| 1080×1920 | 原生 9:16 等比全屏，不裁切、不套框、不虚化；另烧字幕和接同尺寸尾板。 |
| 1920×1080 | 用原片等比放入对应语言横版卡套。 |
| 1080×1080、1080×1350 | 从同一母片适配对应语言和尺寸的卡套。 |

虚化只在本批明确要求时使用；不从套框成片继续转比例，或把尾板变形拉伸。每款尾板看实际 CTA 与语言、尺寸一致。统一输出 MP4、H.264、AAC、30fps。海外名按提供的模板填写，例如 `EN=OB=UA=V0000=1920x1080=PROJECT=OWNER=99=YYYYMMDD=x=x.mp4`；项目代号、日期、编号、末尾字段以本批为准，不沿用示例值。

## 4. 样片、批量、质检

- 新样式先做一条原生竖和一条延展样片；带旧字的选有最长句、停顿和换句的素材来验。确认读感、口音、速度、遮盖、BGM、尾板后固化样片参数，再批量。
- 每条探测真实编码/尺寸/帧率/音轨，跑完整解码，按编号 × 语言 × 尺寸对账。抽查开场、中段、最长字幕、换句、口播结尾和尾板；已有音轨要求保持不变的返工，能原样复制时校验音轨哈希。
- 分开交付成片、SRT、对齐 WAV、质检或异常清单。实际放到用户点名的目录才算交付。改名先查同名冲突；旧版要替换时先备份，遇文件占用留下可定位的新版并报告。

## 简中双尺寸分支

输入已带简中文字及原声的正片。原字幕、原声不重做；原生竖版直接 1080×1920 全屏，横版 1920×1080 用已确认的简中卡套（本机曾用简中卡套的 `简.png`，本批仍要验证透明窗口匹配 9:16）。各接对应尺寸的简中尾板，体验/预约/下载由用户指定，不凭文件名猜。按正式标题只替换真实尺寸字段；不额外生成字幕或配音。依上述规则逐条质检。
