# 海外完整本地化与简中适配 SOP

## 前置资产与矩阵

- 纯净母片（无中文字幕/口播，尽量保留音乐、音效）及中文版参考；或者只有带烧录中文字幕和中文原混音的成片。
- 确认目标语言和文案，给必要的术语表及发音要求。
- 每种目标语言的已确认 WAV；若没有，提供可使用的参考 WAV、参考台词和具体声音要求。仅有混音版且需另配乐时，提供独立 BGM；要保留独立音效须另给音效轨。
- 对应语言和尺寸的 PNG 卡套、尾板（语言/实际尺寸/CTA）、素材编号题材表、日期命名和目标目录。
- 用本批给出的原片、目标语言、尺寸、CTA 和实际加字幕/配音的范围建立矩阵，不预设语种、尺寸或数量。缺资产记行，不拿其他语言代替。

## 1. 选择母片与声音路线

有纯净版则只用纯净母片画面，保留音乐与音效；新版台词使用目标语言。只有中文混音版则静音主体原轨，使用独立 BGM＋目标语配音，并记录每段旧字幕出现区间及画幅上的边界。确认原片是否已有尾板，若有则从精确首帧裁除画面与声音；主体播放速度不改。

有确认 WAV 优先复用；需要生成时按 [VoxCPM 安装与生成](voxcpm.md) 操作。每条原片、每语言仅制作一套对齐 WAV 和字幕时间线，供不同尺寸复用。相同脚本在不同片长原片上的对齐参数需各自计算。

## 2. 配音时长、字幕和混音

1. 先确认要求逐镜同步还是只对齐结尾，以及尾板前预留多长。测最后有效发音时间而不是 WAV 容器时长。口播过长先处理停顿、适度调速，仍不合适就调整译文重生成；不意外截断最后一句。
2. 对齐确认稿与最终发音时间。词级时间戳可作为辅助，再复核专名和数字。按本批配置烧录字幕或输出独立 SRT；字体、行数、字号、位置和颜色不沿用历史偏好。检查可用画面内字形完整。
3. 有烧录字且当前项目采用遮罩时，测原字出现区间及位置。动态底板至少覆盖旧字边界和新字幕尺寸，含边距；换句、停顿和前后帧也不得漏字。不预设底色、描边或圆角。
4. 混音分轨调节并试听，检查口播、BGM 和尾板声音过渡。增益、压限参数和尾板前留白以此项目的验收值为准，不继承其他批次。

## 3. 画幅、尾板与成片

| 输出 | 处理 |
| --- | --- |
| 与原片比例相同 | 无额外包装要求时保留原构图。 |
| 跨比例 | 根据当前项目选定卡套、扩展背景或其他布局，从同一母片独立生成。 |

避免重复包框或拉伸错尺寸尾板。尾板的实际 CTA、语言和尺寸与配置对应。输出规格和命名模板由任务给定，命名中的尺寸和语言与实际内容核对。

## 4. 样片、批量、质检

- 新样式先做代表样片，覆盖本次有风险的画幅及遮盖场景；带旧字的选有最长句、停顿和换句的素材来验。确认读感、口音、速度、遮盖、BGM、尾板后固化样片参数，再批量。参见 [实际本地化脚本](execution-record.md#本地化与画幅适配)。
- 每条探测真实编码/尺寸/帧率/音轨，跑完整解码，按编号 × 语言 × 尺寸对账。抽查开场、中段、最长字幕、换句、口播结尾和尾板；已有音轨要求保持不变的返工，能原样复制时校验音轨哈希。
- 分开交付成片、SRT、对齐 WAV、质检或异常清单。实际放到用户点名的目录才算交付。改名先查同名冲突；旧版要替换时先备份，遇文件占用留下可定位的新版并报告。

## 保留已有语言的适配分支

输入已验收字幕和原声的正片。保持主体字幕和声音，不重新生成字幕或配音。按项目规定调整画幅、卡套、尾板、CTA 和命名，再逐条质检。
