## 4. A面字幕与转场切点示例

转写后先人工检查完整台词。假设词级时间戳为：

```json
{
  "horizontal": {
    "last_sentence": "我一定会回来的",
    "last_spoken_character": "的",
    "transition_start": 10.28,
    "speech_end": 10.48
  },
  "vertical": {
    "last_sentence": "分手",
    "last_spoken_character": "手",
    "transition_start": 7.96,
    "speech_end": 8.20
  }
}
```

正确做法：横版从最后一个“的”开始推近，竖版从最后一个“手”开始推近；A画面继续运动，A原声保留到真实结束。

错误做法：

- 横竖都使用 `10.28`。
- 从“我一定会回来的”整句开始时就转场。
- 转场前把A最后一帧定格。
- 转场开始时直接切断A声音。

## 5. B面旧尾板示例

分别检查每个 B 的横竖文件尾部。假设核验结果为：

```json
{
  "V9001": {
    "horizontal": 40.700,
    "vertical": 40.733,
    "verified": true
  },
  "V9003": {
    "horizontal": 30.267,
    "vertical": 30.300,
    "verified": true
  }
}
```

渲染时同时 `trim` 视频、`atrim` 音频。B→C 从对应裁切点前 `0.4秒` 开始推近。不得保留旧尾板后再追加新尾板。

## 6. 样片验收示例

批量前只产一条：

```text
体验/失恋逆袭+V9001+弱者反击+横.mp4
```

检查清单：

- 最后一个字开始时才出现 A→B 推近。
- A画面未静止，A最后一句声音完整。
- A→B 为推近加四周轻微模糊。
- B旧尾板已删除。
- B→新体验尾板使用相同推近加四周轻微模糊。
- 两个转场都有声音，没有突然静音。

只有用户明确确认样片后，才扩展到其余版本。

## 7. 批量数量与命名示例

本例选择 2 个 B。每个 B 产出：

- 横原生预约、横原生体验。
- 竖原生预约、竖原生体验。
- 横原生转成竖包框的预约、体验。
- 竖原生转成横包框的预约、体验。

因此总数为 `2个B × 2个原生画幅 × 2个尾板版本 × 2种输出形态 = 16条`，预约8条、体验8条。

部分正确命名：

```text
预约/失恋逆袭+V9001+弱者反击+横.mp4
预约/失恋逆袭+V9001+弱者反击+竖.mp4
预约/失恋逆袭+V9001+弱者反击+竖包框.mp4
预约/失恋逆袭+V9001+弱者反击+横包框.mp4
体验/失恋逆袭+V9003+平民阵容翻盘+横.mp4
体验/失恋逆袭+V9003+平民阵容翻盘+竖包框.mp4
```

B面文件名 `G36-V9001-...;ae;逆袭;战力;弱者反击.mp4` 的 B面名称只能取最后一段“弱者反击”，不能把前面的标签写进成片名。
